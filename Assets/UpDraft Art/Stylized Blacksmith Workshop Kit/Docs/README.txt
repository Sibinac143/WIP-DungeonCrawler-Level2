QUICK START (UNITY)
1. Import the package into your project.
2. Open the demo scene:
Assets/UpDraft Art/Stylized Blacksmith Workshop Kit/Scenes/Blacksmith_Demo.unity
3. Drag prefabs from Prefabs/ into your scene.

If any prefab appears pink:
Assign the included atlas material to the renderer:
Materials/M_Blacksmith_Atlas.mat

SCALE, UNITS, AND PIVOTS
- Authored in real-world scale (1 Unity unit = 1 meter).
- Prefab roots are set for clean placement:
Position (0,0,0) / Rotation (0,0,0) / Scale (1,1,1)
- Pivots:
  * Furniture: bottom/floor pivot for easy placement on surfaces
  * Small props: bottom-center pivot for simple rotation/positioning

MATERIALS / TEXTURES
- Single atlas workflow (one primary material for the pack).
- Included textures are located in Textures/:
  * Albedo/Color atlas
  * Smoothness atlas (inverted roughness)
  * Metallic/Smoothness
  * Grime Patch + Soot Ring Textures

Unity import notes:
- Albedo/Color atlas: sRGB ON
- Data maps (Smoothness/Mask/Metallic): sRGB OFF


Render pipeline:
- Tested in: Built-in / URP
- If you switch pipelines, Unity may require a material/shader conversion.
